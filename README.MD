# 🌱 ECO LIFE

**Eco Life** is an eco-friendly e-commerce web application where users can purchase sustainable products with ease. The platform allows users to create accounts, log in securely, browse products, place orders, make payments, and track order statuses, all with a smooth and responsive user experience.

---

## ✨ Features

- User authentication (Sign up / Login)
- Secure authentication using Firebase
- Browse and purchase eco-friendly products
- Order management and order status tracking
- Stripe payment gateway integration
- Fully responsive design for all devices
- Smooth and modern UI using Material UI

---

## 🛠️ Tech Stack

### Frontend
- React  
- TypeScript  
- Tailwind CSS  
- Material UI  
- Firebase Authentication  

### Backend
- Node.js  
- Express.js  
- MongoDB  
- Mongoose  
- JSON Web Token (JWT) for API security  

---

## 🔐 Security

- Firebase is used for secure frontend authentication  
- Backend APIs are protected using JSON Web Tokens (JWT)

---

## 📱 Responsive Design

Eco Life is fully responsive and optimized for all screen sizes, ensuring a consistent experience across desktops, tablets, and mobile devices.

---

## 🚀 Purpose

The goal of Eco Life is to promote sustainable living by making eco-friendly products easily accessible through a modern and secure e-commerce platform.
